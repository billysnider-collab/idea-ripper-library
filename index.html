1Prediction is not agencyPrediction and agency should not be conflated. A credit model can estimate the…argument

Prediction and agency should not be conflated. A credit model can estimate the probability that a borrower breaches a covenant. An agentic credit workflow must additionally determine which documents are authoritative, retrieve the relevant covenant language, reconcile contradictory data, simulate possible interventions, check approval limits, request human authorization when required, execute an admissible action, and preserve an audit trail. Increasing the parameter count of the predictor does not, by itself, supply persistent memory, permissions, transaction semantics, or institutional accountability.

Why it matters: A bigger model buys none of the institutional machinery an agent needs — memory, permissions, transaction semantics, accountability. So 'we upgraded the model' is never an answer to 'who authorized this action,' and agents must be judged on the actions they induce, not the accuracy of their outputs.

Use when a team proposes a stronger model as the fix for an agent that lacks memory, permissioning, or an audit trail.

2Grow the action set on evidence, not fluencyThe technically and institutionally mature objective is bounded autonomy : the agent can…concept

The technically and institutionally mature objective is bounded autonomy : the agent can plan, retrieve, calculate, and propose actions inside a formally defined action set, while external shields enforce limits and humans retain authority over material decisions.

Why it matters: Fluency is the trait everyone watches improve, but it says nothing about whether an agent should be allowed to move money. The book's growth rule: the action set expands only after evidence of reliability, never because the model got more fluent — permissions follow demonstrated trustworthiness, not convincing prose.

Use when deciding what an AI agent is permitted to do in production: which actions stay read-only, which need review gates, which are off-limits.

3Audit the action, not the rhetoricThis principle prevents a common category error. A model that says it will respect a…passage

This principle prevents a common category error. A model that says it will respect a mandate has not yet respected the mandate. A model that produces a prudent explanation has not yet produced an admissible order. A model that refuses a risky request in a benchmark has not thereby proved that a future tool call cannot violate an entitlement or capital limit. The audit object is the action process together with the evidence and controls surrounding it, not the rhetorical quality of the model’s answer.

Why it matters: Benchmarks test words; real violations happen in tool calls, entitlements, and capital limits. A fluent refusal in a demo proves nothing about the next tool call, so the audit target has to be the action pipeline and its controls — never the explanation quality.

Use when a vendor demo, benchmark score, or red-team chat log is being offered as proof that an agent is safe to deploy.

4Numbers need a citation, not a storyProduction systems should separate language generation from numerical computation. Let…passage

Production systems should separate language generation from numerical computation. Let the LLM propose hypotheses, retrieve context, or explain model outputs, but let audited numerical code compute returns, volatilities, correlations, drawdowns, and portfolio weights. A forecast report should include confidence intervals, calibration diagnostics, and explicit uncertainty. If the model cannot cite the data and computation behind a number, the number should not enter the investment process.

Why it matters: Fluency around a number feels like evidence for it, but small numerical errors drive large position changes. The fix is architectural — audited code computes, the model explains — not a better prompt.

Use when an LLM-generated forecast, ratio, or expected return is about to enter a report, model, or trade.

Large Language Models in finance are best understood as part of a pipeline rather than as a point solution. 11RAG's two controlsTwo things distinguish it from a generic one, and both are controls rather than models.…mechanism

Two things distinguish it from a generic one, and both are controls rather than models. The availability filter D ≤ t admits only documents that existed at the decision time t , which is what stops a backtest from reading tomorrow’s filing. The claim-level verifier checks each material claim A i against its retrieved evidence bundle E i before the answer is released, which is what stops a fluent answer from being an unsupported one.

Why it matters: A RAG system fails in exactly two places that matter: letting the future leak in (the availability filter) and letting fluent prose out without evidence (the claim verifier). Everything else — embeddings, chunking, reranking — is optimization inside those two guardrails.

When evaluating a RAG build, check the two controls first: does retrieval enforce the decision-time cutoff, and does anything verify claims against evidence before release?

12MCP is a protocol, not a governance frameworkMCP is an interoperability protocol, not a complete governance framework. A regulated…argument

When wiring MCP tools into a regulated workflow, build the control envelope first: identity, least-privilege auth, typed contracts, approval gates, audit records.

15Performance is not a single-number propertyFor generative systems, quality is vector-valued. A financial LLM is not judged only by a…argument

For generative systems, quality is vector-valued. A financial LLM is not judged only by a semantic metric such as ROUGE, BLEU, cosine similarity, or pairwise preference. Synthesis

Morris tells how post-Roman Britain’s wreckage, Germanic settlement, and warlord kingdoms became—unevenly—a Christian people and then a kingdom called England. He refuses timeless “Anglo-Saxon” generalizations, tracking change era by era through collapse, kingship, conversion, Mercian empire, viking storm, Alfredian resurrection, West Saxon reconquest, monastic reform, renewed Scandinavian conquest, and Norman twilight. English identity appears first as ethnicity and Church belonging, then as Alfred’s political *Angelcynn*, then as Æthelstan’s *Rex Anglorum* and Æthelred’s *Engla-Lande*. Institutions (burhs, shires, coinage, minsters) accumulate under pressure but repeatedly fail when succession, faction, or overstretch intervene. By 1066 England exists strongly enough that replacing its aristocracy does not delete the country.

  1. England is made, not remembered whole from 449.
  2. Shared Englishness is a political and religious project —especially against Britons and under viking duress.

Chapter thesis: This chapter argues that Roman Britain's prosperity and security collapsed in the early fifth century through imperial military and economic withdrawal, internal usurpations, and barbarian raids, and that the subsequent Anglo-Saxon settlement was a complex, multi-phase migration that transformed the province into a divided and degraded Britain.
