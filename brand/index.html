7 · The lock — Billy's checklist

  • Product name stays IDEA RIPPER — no renames, no "Book Job" / "Contraband Library" titles
  • One decisive red tear through RIPPER — legible after the cut
  • Torn-page R as favicon / seal, separate from the wordmark
  • Keeper cards: yellow STOLEN tab + red annotation mark
  • Kill / rewrite / ungraded cards get NO yellow tab (data-status hook is live)
  • Feel: publishing imprint + field notebook + slightly illicit tool
  • Flat ink, rough torn edges, red-pencil underlines — no AI/SaaS gloss
  • Mono version reads in single-color print
