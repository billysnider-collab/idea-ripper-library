Card #c558IR // #c558Synthesis

The root of evil (and of bad habits, dysfunction, self-sabotage) is not malice or weak will but ignorance: 'Ignorance is the mother of all evil.' The mechanism follows: a hidden root is strong, but the moment it is recognized it is dissolved. A problem you can't name keeps running you; a problem you accurately name has already lost most of its grip.

— In our words · Source: The Nag Hammadi Library

[Use when]

Use when a recurring problem resists every fix — stop and hunt for the unrecognized root. Use when doing an honest post-mortem of a personal or team failure. Use when someone keeps fighting symptoms and nothing improves.

[Why it matters]

It shifts remediation from willpower or condemnation to diagnosis. If the real problem is that you can't see the root, the fix is recognition, not harder effort against the symptoms. It explains why problems survive for years while looking 'obvious' to outsiders — the person inside can't see the root, so it stays strong. It reframes error as blindness to be cured, not sin to be punished.
