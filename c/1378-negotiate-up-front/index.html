"“Did you negotiate anything?” Because Mathew had a philosophy that you negotiated up front so that you wouldn’t have to pay so much later."

— In our words · Source: Matriarch (Tina Knowles)

[Use when]

A collaborator is about to start work and nobody has discussed price.

[Why it matters]

Once someone in high demand has already done the work, you have little leverage over the bill. Mathew's rule was to settle terms before any work started.
